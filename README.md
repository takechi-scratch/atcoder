# AtCoder解答集
takechiが書いたAtCoderの解答コードです。
コード内に記載がない限り、ACしたものです。

感じたことやヒントなどをコードに書いているので、良ければ参考までに。
一部の問題には自作のテストケース`selftest-*`や、関連するコードなどもあります。
